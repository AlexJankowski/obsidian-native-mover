# This plugin enables key modifiers for moving files and folders outside Obsidian Vault

To activate it simply press modifier **before** dragging file from obsidian explorer

## Following modifiers are available so far
* Use **Ctrl** To _copy_ file/folder to wherever you drop it
* Use **Alt** To _create default OS link_ to the file/folder wherever you drop it
* Use **Alt+Ctrl** To _move_ file wherever you drop it (note that you need to focus back on obsidian window to finish operation)
	* By Default original moved file will be simply moved to vault's .trash folder and coppied wherever you dropped it. You can enable dedicated setting to remove it completely from the vault when moving file/foldee outside obsidian (use with caution as you may lose data if moving was interupted)
 * If no key modifier applied default _obsidian link_ will be created on drop 	

TESTED ON WINDOWS 10 ONLY
